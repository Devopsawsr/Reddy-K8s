# Deployment evidence

Store screenshots or text output demonstrating:

- kubeadm nodes in Ready state
- all application pods running
- service and endpoint discovery
- successful smoke test
- pod recreation after deletion
- manual scaling
- failed rollout and successful rollback
- HPA output after metrics-server is installed
- successful GitHub Actions pipeline
- Argo CD synchronized applications
- EKS workload and load-balancer status

Do not commit credentials, kubeconfig files, tokens, private keys or unredacted secrets.
